## What changed since 1.0.0

User-visible:

- **Repeat downloads go to a sibling folder.** Clicking `Saved · NP` again saves the artwork into `pixiv/<artist>-<id> (1)/` (then `(2)`, …) with clean file names instead of ` (1)` suffixes on each file inside the first folder. The tooltip names the folder used. A folder moved away or deleted frees its name again (PRD-000 §4.3 "Folder choice", D15).
- **Two downloads started at the same instant no longer fail files.** Two artworks clicked in two tabs within a few milliseconds both finish with every page and `metadata.json` (iteration-4 LOW, D16).
- Settings-page links and the selected segment use `#0b6fc2` in light mode for 4.5:1 contrast (R-007 item 4).
- A Retry after both the pages and `metadata.json` failed re-writes `metadata.json` (R-007 item 6).

No change to permissions, host permissions, storage shape or the store listing text. The update installs over 1.0.0 without a new permission prompt.

Verification: dev-cycle iteration 5 ([qa-report.md](../qa-report.md), run `iter5-00-09-39`, verdict FAIL with 1 LOW, accepted by R-008 option A as a spec limitation; [pm-review.md](../pm-review.md), all five CUJs Satisfied; [code-review.md](../code-review.md), 0 critical).
